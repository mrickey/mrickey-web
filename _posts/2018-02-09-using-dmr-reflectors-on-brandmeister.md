**Update 2018-10-09: Reflector functionality has been removed from US Masters.**In the early days of DMR, mostly in Europe, DMR repeaters used the DMR+ network. This network is reflector based, much like how D-STAR works. Before getting very far into the discussion, it is important to know there are talkgroups associated with each of the reflectors. The only advantage to a reflector is it's dynamic nature...being able to use them without programming channels. However, several of the modern DMR radios allow you to manually enter group call IDs, this negates the need for reflectors.[Read More](/2018/02/09/using-dmr-reflectors-on-brandmeister/)
