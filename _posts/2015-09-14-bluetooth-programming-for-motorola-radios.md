<span style="font-family:Verdana, sans-serif;">Motorola offers the ability to program some of their radios using Bluetooth instead of a cable. This is a great feature that offers a lot of convenience. But, there are a couple of little tricks you need to know in order to get this working.</span><span style="font-family:Verdana, sans-serif;"></span><span style="font-family:Verdana, sans-serif;">To help people along, I created a video that demonstrates the process. Here are the steps, watch the video for more specifics.</span>1. <span style="font-family:Verdana, sans-serif;">On the PC - Type "Devices" in the search box, click on "Devices and Printers" highlight and remove any Motorola icons</span>
2. <span style="font-family:Verdana, sans-serif;">Turn on the Radio, go to Menu → Bluetooth → Find Me</span>
3. <span style="font-family:Verdana, sans-serif;">On the PC, Type "Add a Bluetooth Device" in the search box. In the list of devices you should see your radio. Select it and click "Pair"</span>
4. <span style="font-family:Verdana, sans-serif;">On the radio, "Accept" will be highlighted, select "OK"</span>
5. <span style="font-family:Verdana, sans-serif;">On the PC ignore the code, select "Yes" to pair</span>
6. <span style="font-family:Verdana, sans-serif;">Back on the "Devices and Printers" page click your radio to highlight it and click on "Connect Using" then click on "Access Point", this will pair the PC with the radio and you will hear a connect tone from the radio.</span>
7. <span style="font-family:Verdana, sans-serif;">In CPS, click the Bluetooth icon, it will turn blue. Use the default IP address.</span>

<span style="font-family:Verdana, sans-serif;">You can now program the radio.</span><span style="font-family:Verdana, sans-serif;"></span><div style="clear:both;text-align:center;"><span style="font-family:Verdana, sans-serif;">\[youtube https://www.youtube.com/watch?v=U29HRmn6SIA?feature=player\_embedded\]</span></div><span style="font-family:Verdana, sans-serif;">Once you have completed pairing, you will only need to using steps 6 and 7 to program your radio.</span><span style="font-family:Verdana, sans-serif;"></span><span style="font-family:Verdana, sans-serif;">I have used this process on the Motorola XPR7550, SL7550, and the XPR5550. They all work the same way. The same process works on Windows 8 and Windows 10. It should work the same on Windows 7, but I don't have a machine available for testing.</span><span style="font-family:Verdana, sans-serif;"></span><span style="font-family:Verdana, sans-serif;">Let me know in the comments if you have any problems or suggestions.</span><span style="font-family:Verdana, sans-serif;"></span>
