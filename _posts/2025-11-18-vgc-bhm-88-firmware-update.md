VGC Has released their new Bluetooth speaker mic. The BHM-88 is available in black and tan and works with all of the "N" series radios.

I have the non-display version of this microphone and it works really well. The addition of the display is interesting to me, not so much for use with a hand-held radio (like my VR-N76) as it is for the mobile VGC VR-N7500 I have. This radio has no display at all. Using the BHM-88 will give me a display and a better ability to use the radio on the go.

In addition to the VGC radios, this microphone will pair with the Icom IC-705. It does not give a frequency display, but it does work as a speaker mic.

## Firmware Update 0.3.4 (2025-11-17)

I received email about this update earlier today. They are adding a number of new features in this update. In general, I like how VGC does a lot of firmware updates to keep their radio working well and continues to add features.

- **New Display Feature:** Support for displaying the **Group Name**.
- **Expanded Mode Support:** Added support for **Frequency Mode**, **Satellite Mode**, and other related modes.
- **Enhanced Synchronization:**
    - Support for **Device Language Synchronization**.
    - Support for **Time Zone Synchronization**, fixing the previous issue where time zone settings did not work correctly.
- **New Adjustment Setting:** Support for modifying the **Frequency Offset**.
- **Improved Main Interface Navigation:**
    - Use the **Up/Down buttons** to switch between channels and VFO frequency on the main screen.
    - **Long-press the Right Soft Key** to switch between the Main and Sub channels. ![](https://ci3.googleusercontent.com/meips/ADKq_Nb98zHNUepsj-fJy1v1kZlMoHvNdFjBLjl5QEtWUrOS_DmdXV9X8hWSHKIMPS7aaDjoV6FM1a3gCCUAOxAO2tLWmr5jDAY6iz4X-2zNXnySHrhATgsQlJbc_Z-BsabRkPkj_xQ7qknLuOz1ljGPMCU2qtvfc_en1EE=s0-d-e1-ft#https://mcusercontent.com/8ae7b059e5953eba78f8283f2/images/ab35c54c-ddb5-91f5-7b8c-c1c337f6e5f3.jpg)
- **New Visual Indicator:** A **speaker icon** is now displayed on the left side if the last received channel is different from the currently selected channel.
- **Critical Bug Fix:** Resolved an issue where **edited frequencies might not save correctly**.

They recommend all users install this update to benefit from the new features and improved stability.
